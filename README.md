## 🚀 Featured Projects

### 🧪 [LabSphere – Smart Pathology Lab Platform](https://github.com/krrishmahar)
End-to-end LIMS to digitize, organize, and streamline diagnostic workflows across India.
- Built with **Next.js**, **PostgreSQL**, **Supabase**, and **Twilio**.
- Automated appointment scheduling, lab report workflows, and resource allocation.

### ⚡ [Technetics 2K26 Central Portal](https://github.com/krrishmahar)
Official event platform for the Technetics 2K26 college festival.
- Built with **Next.js**, **React**, **Framer Motion**, deployed on **Vercel**.
- Immersive themed UI, interactive schedules, sponsor hubs.

### 📦 [Go Wiki DevOpsified](https://github.com/krrishmahar/go-wiki-devopsified)
Automated CI/CD: Jenkins & GitHub Webhooks → Dockerized Go App → AWS EC2 + Nginx.
> **Tools:** Go, Docker, Jenkins, AWS EC2, Nginx, Webhooks

### 🏗️ [Java 3-Tier Enterprise Web App on AWS](https://github.com/krrishmahar/Java-App-on-AWS-3-Tier-Architecture)
Three-tier architecture: EC2 (Compute), RDS (Database), S3 (Assets), Nginx reverse proxy.
> **Tools:** Java, AWS EC2/RDS/S3, Tomcat, Nginx

### 🏨 [Veda Hotel Booking Platform](https://github.com/krrishmahar/veda-app)
Full-stack hotel reservation app with automated CI/CD.
> **Tools:** React, Spring Boot, MySQL, Docker, GitHub Actions
